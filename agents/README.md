# Engineering & Archive Agents

This directory documents the specialized review roles used to keep **Our Childhood** consistent, accessible, culturally accurate, and easy to expand.

- [`architecture-agent.md`](architecture-agent.md) — Ensures separation of content and presentation, template reusability, and clean TypeScript boundaries.
- [`content-agent.md`](content-agent.md) — Enforces cultural accuracy, transparent handling of unconfirmed rules, and data-driven content schema compliance.
- [`frontend-accessibility-agent.md`](frontend-accessibility-agent.md) — Enforces mobile-first responsiveness, editorial typography, zero-pill discipline, and WCAG 2.2 AA accessibility.
